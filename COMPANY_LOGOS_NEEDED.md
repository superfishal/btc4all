## Logo Requirements

### Preferred Formats (in order of preference):
1. **SVG** (vector - best quality, scalable)
2. **PNG** (transparent background, high resolution)
3. **SVG.png** (if SVG not available)

### Specifications:
- **Transparent background** preferred
- **High resolution** (at least 200px width)
- **Horizontal/landscape orientation** preferred
- **White/light version** preferred for dark backgrounds
- **Black/dark version** available as backup

### File Naming Convention:
- Use lowercase with underscores
- Example: `steak_n_shake_logo.png`
- Example: `home_depot_logo.svg`

## Search Tips

When searching for logos:
- Search "[Company Name] logo SVG"
- Search "[Company Name] brand assets"
- Check company's official brand/logo resources page
- Use sites like: logos-world.net, brandfetch.com, brandassets.com
- Ensure you have permission to use the logos (most brand logos are fine for display purposes)
